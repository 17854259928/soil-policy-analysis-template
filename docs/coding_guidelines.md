# Soil-policy coding guidelines

## Inclusion rule

Code a record as soil-policy relevant only when the supplied source explicitly
states a soil objective, threat, management mechanism, indicator, obligation,
eligibility rule, output or outcome.

## Exclusion rule

Do not include a record solely because it concerns climate, biodiversity,
organic farming, water, fertilisers or agricultural sustainability. Include it
only if the source makes the soil pathway observable.

## Results-chain rule

Keep the following stages distinct:

1. policy design;
2. planned target;
3. public expenditure or administrative input;
4. farmer or land-manager adoption;
5. implementation output;
6. measured or modelled soil outcome; and
7. broader environmental, production or economic effect.

## Evidence rule

Positive and uncertain codes require local evidence. Store the shortest
quotation that preserves meaning together with page, section, table or row.
Do not use a document-level citation as evidence for every field.

## Numeric rule

Preserve the original number and unit. Do not silently convert currencies,
areas, concentrations, stocks, flows or percentages. Record missing units and
ambiguous denominators as warnings.

## Soil-indicator rule

Where observable, retain soil depth, sampling basis, spatial aggregation,
baseline year, measurement method and whether the value is measured, modelled,
targeted or expected. Values without comparable metadata must not be treated as
directly comparable.

## Uncertainty rule

Use `uncertain` when evidence supports more than one reasonable code. Use
`not_observable` when the field cannot be determined from the supplied source.
Do not use external agronomic knowledge to fill evidence gaps.
